## Create new Role
<p>
Roles define what actions a user can perform in the system.
</p>
To create a new role:
### 1. Create Role
Click on the "Create Role" button.
![chrome_et5i8vojnz](/img/old/rol/chrome_et5i8vojnz.png)

### 2. Naming
Enter the name and description of the new role.
<p align="center">
![chrome_9uzpfwvycd](/img/old/rol/chrome_9uzpfwvycd.png)
</p>

### 3. Assigning permissions
In the permissions section, select the functions you want the role to have.
<p align="center">
![chrome_se7y1qsetf](/img/old/rol/chrome_se7y1qsetf.gif)
</p>

### 4. Done
Click on "Create Role".
<p align="center">
![chrome_kmdm7ldcgw](/img/old/rol/chrome_kmdm7ldcgw.png)
</p>

And that's it! The role has been successfully created.

## Roles

- **Superadministrator:** full access to every workspace and administrative
  section of the company, including licensing, users and workspaces.
- **Custom roles:** roles with granular permissions. Each permission enables a
  specific action in the interface, for example creating sources, editing nodes
  or viewing logs.

Typical permissions include: add/edit/delete **sources** and **destinations**,
create and run **nodes** and **jobs**, view **monitor and logs**, and manage
**workspace settings**.
