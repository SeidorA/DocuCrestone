## Create a Report in Extraction Node 
### 1. Selecting an SAP ABAP system
![SAP ABAP system selection screen](/img/node/Reports/a.png)

### 2. Select extraction type "Report".
![Report extraction type selection](/img/node/Reports/b.png)

### 3. Select the type of transaction

Select a transaction code to search, for example: ‘va05’, or by the technical name of the ABAP program that runs behind a transaction
![Transaction type selection interface](/img/node/Reports/c.png)

### 4. Select a transaction code
![Transaction code selection screen](/img/node/Reports/d.png)

### 5. Select variant if necessary
![Variant selection interface](/img/node/Reports/e.png)

### 6. Click this icon.
![Report Settings navigation for column detection](/img/node/Reports/f.png)

### 7. Select filter
![Report Settings navigation for column detection](/img/node/Reports/g.png)

### 8. Fill in the filters and save
![Fill in the filters and save](/img/node/Reports/h.png)

----- 

### 9. Go to Report Settings to detect the columns
![Report Settings navigation for column detection](/img/node/Reports/i.jpeg)

### 10. Click "Automatically detect columns" to set the width and offset of each column.
![Automatic column detection button](/img/node/Reports/j.jpeg)

### 11. Establish the rows to be omitted if necessary
![Row omission configuration screen](/img/node/Reports/i.jpeg)

### 12. Adding a pattern to skip rows by keyword
![Pattern configuration for keyword-based row skipping](/img/node/Reports/j.jpeg)

### 13. Click on the confirmation button.
![Confirmation button location](/img/node/Reports/k.jpeg)

### 14. Go to Preview to verify that the result is as expected.
![Preview screen showing extraction results for verification](/img/node/Reports/l.jpeg)
