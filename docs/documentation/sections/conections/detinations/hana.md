## How to create a destination with SAP HANA

Setting Up a New SAP HANA Connection

### 1. Naming
Give it a name to be able to identify it 
![Naming](/img/Conections/hana/a.png)

### 2. Select the field
Select SAP HANA from the destination type dropdown menu.


![Select the field](/img/Conections/hana/b.png)


### 3. Enter SAP HANA credentials:
Fill in the data with your SAP HANA credentials.


![SAP HANA credentials](/img/Conections/hana/c.png)


### 4. Click "Test Connection"
![Test Connection](/img/Conections/hana/d.png)

### 5. Create the connection
If the connection test was completed successfully, you can save this destination in your connections.
![Create the connection](/img/Conections/hana/e.png)
